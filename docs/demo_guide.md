# QUANT VECTOR — Demo Guide

A complete walkthrough in about 8 minutes. All commands assume Windows PowerShell from the
`market-dna` folder. The bundled `sample_data/demo_market.csv` is **synthetic** data
(generated by `sample_data/generate_demo_market.py`, seed 42) with three distinct market
phases so every analytics feature shows meaningful results.

## 0. Start everything (~1 min)

```powershell
# Terminal 1 — MySQL service must be running
Get-Service *mysql*          # should show "Running"

# Terminal 2 — backend
cd backend
uvicorn main:app --reload --port 8000

# Terminal 3 — frontend
cd frontend
npm run dev
```

Open <http://localhost:5173>. Confirm the top bar shows the API healthy.

## 1. Upload the demo dataset (~30 s)

- Go to **Datasets** → upload `sample_data/demo_market.csv`.
- Point out: row count, date range, latest close appear immediately; the file was cleaned and
  validated server-side; a new immutable dataset id was created.
- Mention: uploading the same file again creates a *second* dataset — immutability is what
  makes all result caching safe.

## 2. Overview & price chart (~1 min)

- **Overview** page for the active dataset: headline stats (total return, annualized
  volatility, max drawdown) plus the interactive price chart.
- Hover to show tooltips; note the N/A-safe formatting of short histories.

## 3. Statistical fingerprint (~1 min)

- **Fingerprint** page: four families — return, risk, trend, behaviour characteristics.
- Highlight skewness/kurtosis ("fat tails"), autocorrelation lags, MA alignment label.
- Note that categorical entries never degrade storage: numeric metrics persist in MySQL,
  labels stay API-only.

## 4. Historical analogues (~1.5 min)

- **Analogues** page, lookback 60: the engine standardized features, compared every earlier
  disjoint window by distance, applied temporal suppression, ranked the best matches.
- Open one match's details: similarity score + what historically followed (+5d/+20d).
- Emphasize the wording on screen: observations of the past, not forecasts.

## 5. Regime discovery (~2 min)

- **Regimes** page: run discovery with defaults (window 60). PCA compresses standardized
  window features; KMeans groups them; silhouette/Davies–Bouldin picked k automatically.
- Walk through: regime profiles table, timeline strip, transition matrix, conditional
  outcomes per regime.
- Re-run once with forced k=3 vs auto to show determinism and the `auto_selected` flag.
- **Current regime**: the live window is projected onto the model — which regime are we in,
  with what confidence?

## 6. Intelligence scorecard (~1 min)

- **Intelligence** page: trend / analogue / regime / risk evidence tiles, weighted bias,
  confidence meter, contradictions panel, prose summary generated deterministically.
- Second visit loads instantly — point out the parameter-hash snapshot cache in MySQL.

## 7. Compare workspace (~1.5 min)

- **Compare** page: select the demo dataset plus any second dataset (upload another copy or
  your own CSV).
- **Metrics tab**: metric matrix, normalized performance chart, fingerprint similarity.
- **Cross-market tab**: correlation heatmap (Pearson/Spearman/downside/upside), rolling
  20/60-day correlation chart, regression view (beta, R², residual vol) with scatter+fit.
- Save the selection as a **preset**, reload it, rename it — presets survive dataset
  deletion (stale ids are filtered on load).

## 8. Report export (~30 s)

- **Report** page: composed sections with disclaimers; use the print button (browser
  print-to-PDF) — dark theme flips to a light print stylesheet, charts render cleanly,
  page-break rules keep sections intact. CSV/PNG exports work per widget.

## Talking points if asked

- Why returns, not prices → scale-free comparison (methodology §A/K)
- Why caching is safe → datasets immutable, parameter-hash keys, `latest_market_date` guard
- Why MySQL → relational integrity, cascade deletes, indexes, JSON payloads (dbms_notes.md)
- Where formulas live → `docs/quant_methodology.md`, mirrored by `methodology` fields in API
